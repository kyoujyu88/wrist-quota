# wrist-quota
これから始まるストーリー

Claude Code や Codex の「利用枠の残り」と「リセットまでの時間」を PC で集計し、[ntfy](https://ntfy.sh/) 経由でスマートフォンとスマートウォッチへ通知する常駐ツール。

- 残量がしきい値（既定 20%・10%・5%）を下回ると通知する
- 通知した利用枠がリセットされると知らせる（PC が止まっていても届くよう、ntfy に予約する）
- ブラウザで開くローカルの設定画面で、残量の確認と通知内容の設定ができる
- 各ツールが PC 上に書き出す情報だけを読む。認証情報は読まず、外部への通信は ntfy サーバーだけ

仕様は [SPEC.md](SPEC.md)、進み具合は [docs/PROGRESS.md](docs/PROGRESS.md) にある。現在は M1（最小構成）で、実際の ntfy.sh への送信はまだ確認していない。

## 使い方

Go 1.27 以降でビルドする。

```bash
go build ./cmd/wrist-quota
./wrist-quota            # 常駐して収集・通知し、設定画面を配信する
./wrist-quota status     # いま取得できる利用枠を表示して終了する
```

起動すると設定画面の URL（既定は http://127.0.0.1:47821/ ）が表示される。

1. 「通知先」に表示されるトピックを、スマートフォンの ntfy アプリで購読する
2. 「テスト送信」で届くことを確認する
3. 「プロバイダ」で Claude Code のステータスラインに登録する（Codex は登録不要）

トピック名は初回起動時にランダムに作られる。名前を知っていれば誰でも購読・投稿できるので、パスワードと同じ扱いにすること。

## 開発

```bash
go test ./...
go vet ./...
```

設定と状態は OS の設定ディレクトリ配下の `wrist-quota/`（Linux では `~/.config/wrist-quota/`）に JSON で保存される。`WRIST_QUOTA_HOME` で場所を変えられる。
